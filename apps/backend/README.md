# Framework & Philosophy

This service is built using *NestJS v11.0.1*.

[Nest (NestJS)](https://nestjs.com/) is a framework for building efficient, scalable Node.js server-side applications. It uses progressive JavaScript, and is built with and fully supports **TypeScript**.

---

### 📖 Documentation & Learning

To ensure a complete understanding of the architecture and patterns used in this repository, it is **HIGHLY RECOMMENDED** to read the official Nest.JS documentation.

> [!IMPORTANT]
> If you are new to the codebase, at the very least, please read the **[NestJS Overview](https://docs.nestjs.com/overview/modules)** to understand the core concepts of Modules, Controllers, and Providers.
